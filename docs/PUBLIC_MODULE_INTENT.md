# Public/reusable module intent

The long-term architecture should make Pad Sensei theory reusable outside 64 Pad Explorer without making 64PE itself the dependency.

Likely consumers include static educational sites, DOJO, 64PE Desktop/Web, future authoring/sequencer tools, and small standalone examples.

Distribution/publication policy remains a separate decision from module boundaries; reusable architecture does not require immediate npm publication.
