# Long-term static-site goal

Pad Sensei educational articles should be able to become executable explanations.

A page should be able to contain, independently or together:

- a sounding example;
- a chord detector;
- a scale/mode visualization;
- a progression with corresponding pad shapes;
- Shell/UST analysis;
- optional MIDI interaction.

The article remains ordinary static HTML. Pad Sensei functionality is attached as small reusable modules/components rather than by embedding the full application.

This is not a requirement to make every module public immediately; it is an architecture target that prevents new theory features from being trapped inside one application.
